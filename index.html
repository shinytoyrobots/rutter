rutter keeps a record of what you decided, which notes the session cited, and how your thinking changed. Once it is registered in each client and pointed at the same notes folder, each can recall the same records. They are stored as plain Markdown in a folder you own.

Six clients capture and recall: Claude Code, Codex, Grok, GitHub Copilot CLI, Antigravity CLI (agy), and Muse Code. Any other MCP client can recall what they wrote. Capture needs the client's hook to run and the model to leave a line.

One memory. Multiple agents.

Most AI memory belongs to the tool that created it. Switch tools and you start again.

rutter does not belong to a tool. A decision captured in one agent is recalled in another. The agent changes; the memory does not.

"Shared" means one person's agents sharing one memory. It does not mean shared between people.

Six clients, one memory

Using something else? Any MCP client can search and recall with one config entry. It cannot capture, because capture needs a hook.

A record, not a summary

A summary on its own is an assertion. rutter stores the summary together with the notes it cited, and a hash of each note's contents taken when the line was captured. That pair is a record you can compare against later. The worked example shows one end to end.

Inspectable by design

Records are append-only, dated Markdown files in your own notes folder. You can read them in a terminal and commit them to git. rutter infers no profile of you. A reference it cannot place is shown to you as unresolved, not dropped.

Honest fit and limits

  • A line exists only if your client wrote one and its hook found it.
  • A reference shows which notes the session listed, not that the model read them.
  • A note that changes in place, at the same path, is not flagged today.
  • rutter is one person's tool, MIT-licensed and published as a reference implementation, with no support commitment.

The full list is in what rutter can and cannot establish. It suits someone who keeps Markdown notes and is comfortable configuring an AI client.
