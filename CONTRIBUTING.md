# Contributing

rutter is a personal tool shared as a reference implementation. **It is not accepting outside
contributions**, and pull requests are unlikely to be merged. See the README for the support posture.

You are welcome to:

- **Fork it** and take the ideas. The code is MIT licensed.
- **File an issue** if you find a bug or something unclear. There is no guarantee of a response.
- **Report a security problem** privately, as described in [`SECURITY.md`](./SECURITY.md).
